# 🍽️ Avant-Garde Gastronomic Festival 🎨

## 📖 Project Overview
This project consists of a high-end web interface designed for a vanguard gastronomic festival. The main objective is to offer an elegant and modern digital experience that highlights culinary excellence through a visually impactful and functional design. 🚀

## 🛠️ Technologies Used
To build this site, the following tools were used:
* **HTML5**: Semantic content structure, including tables for schedules and native video integration 🏗️.
* **CSS3**: Custom visual design using variables, Flexbox, and Grid to achieve a responsive and sophisticated layout 💅.
* **Multimedia**: Integration of professional video and a high-resolution image gallery to enhance the user experience 📸.

## 📂 Project Structure
The site is organized into the following key sections:
* **Home (index.html)**: Contains the operating hours, an interactive gallery, and a promotional video for the festival 🏠.
* **Menu (menu.html)**: A dedicated page detailing the gastronomic offerings, categorized into dishes, cocktails, and desserts with structured pricing 📜.
* **Reservations**: A functional section for users to select the date, time, and number of guests 📅.
* **Meet Our Chefs**: A space dedicated to introducing the co-founding chefs and culinary leaders of the event 👨‍🍳.

## 🚀 Installation and Usage
If you want to view this project locally, follow these steps:
1.  **Clone the repository**:  
    `git clone https://github.com/rodriguezvjhona-droid/Festival-Gastron-mico-de-Vanguardia-html.git` 💻
2.  **Navigate to the project folder** 📂.
3.  **Open the main file**: Run the `index.html` file in your preferred browser to start the experience 🌐.
